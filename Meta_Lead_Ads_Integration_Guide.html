Integration Guide & Documentation

Meta Lead Ads to CRM Integration

Complete A-to-Z Manual for Setting Up, Configuring Tokens, Subscribing Webhooks, and Testing

1. Overview & Architecture

This document details the complete end-to-end process for linking a Facebook Page's Instant Lead Forms to an automated CRM webhook endpoint using the Meta Graph API (v25.0).

Core Workflow Architecture
User Fills Lead Form on Facebook → Meta Fires Webhook Payload → Python Backend Receives Event → CRM Fetches Lead Details via Graph API → Saved to Database.

2. Step-by-Step Setup Pipeline

Phase 1: Meta Business & App Setup

  1. Create Lead Form: Go to Meta Business Suite → All Tools → Instant Forms → Create a form (e.g., Test Lead Form) and publish it.
  2. Create Developer App: Go to developers.facebook.com/apps → Create App → Select Others → Choose Business app type.
  3. Link Business Portfolio: Select your Meta Business Portfolio during creation to prevent security access blocks.
  4. Note Credentials: Copy your App ID and App Secret from Settings > Basic.

Phase 2: Webhook Subscription Configuration

  1. In Meta App Dashboard, add the Webhooks product.
  2. Change the dropdown at the top from User to Page.
  3. Click Subscribe to this object and enter:
    • Callback URL: https://yourdomain.com/api/webhooks/meta
    • Verify Token: Matches META_VERIFY_TOKEN in your CRM .env.
  4. Locate leadgen in the field list and click Subscribe.

3. Token Generation Pipeline (Permanent Page Access Token)

Follow these exact terminal commands (Windows Command Prompt or Linux Terminal) to generate a page token that never expires.

Step A: Obtain Short-Lived User Access Token

Open Graph API Explorer, select your App, select permissions (leads_retrieval, pages_read_engagement, pages_manage_ads, pages_manage_metadata), and click Generate Access Token.

Step B: Exchange for 60-Day Long-Lived Token

curl -X GET "https://graph.facebook.com/v25.0/oauth/access_token?grant_type=fb_exchange_token&client_id=YOUR_APP_ID&client_secret=YOUR_APP_SECRET&fb_exchange_token=SHORT_USER_TOKEN"

Step C: Fetch Permanent Page Token & Page ID

curl -X GET "https://graph.facebook.com/v25.0/me/accounts?access_token=LONG_LIVED_USER_TOKEN"

Step D: Link Webhook to Page (Crucial Step)

curl -X POST "https://graph.facebook.com/v25.0/YOUR_PAGE_ID/subscribed_apps?subscribed_fields=leadgen&access_token=PERMANENT_PAGE_TOKEN"

Expected Output: {"success": true}

4. Python Backend Webhook Implementation

from flask import Flask, request, jsonify
import requests

app = Flask(__name__)

VERIFY_TOKEN = "YourSecureVerifyToken123"
PAGE_ACCESS_TOKEN = "EAAR7zT2gSPI..."

@app.route('/api/webhooks/meta', methods=['GET', 'POST'])
def meta_webhook():
    # Verification Handshake (GET)
    if request.method == 'GET':
        mode = request.args.get('hub.mode')
        token = request.args.get('hub.verify_token')
        challenge = request.args.get('hub.challenge')
        
        if mode == 'subscribe' and token == VERIFY_TOKEN:
            return challenge, 200
        return 'Forbidden', 403

    # Incoming Lead Event (POST)
    if request.method == 'POST':
        data = request.get_json()
        if data.get('object') == 'page':
            for entry in data.get('entry', []):
                for change in entry.get('changes', []):
                    if change.get('field') == 'leadgen':
                        leadgen_id = change['value']['leadgen_id']
                        # Fetch full lead payload asynchronously
                        fetch_lead_details(leadgen_id)
            
            # MUST return 200 OK immediately
            return "EVENT_RECEIVED", 200
            
        return "Not Found", 404

5. Testing & Troubleshooting Checklist

Error Status / Message Root Cause Solution / Fix
(#200) Permission missing: leads_retrieval Token was generated without explicit lead retrieval rights. Re-generate User Token in Graph API Explorer with leads_retrieval checked.
webhooks.delivery.rejected Server returned non-200 code or timed out before responding. Ensure Flask route returns "EVENT_RECEIVED", 200 immediately before heavy DB ops.
Required permissions are missing for the app Lead Access Manager in Meta Business Manager is blocking the app. Go to Business Settings > Integrations > Leads access > CRMs and assign your App.
404 Not Found in Testing Tool Callback URL path mismatch or endpoint not live. Verify cPanel app is running and URL path matches Flask route exactly.
