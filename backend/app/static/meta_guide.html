🚀 Meta Lead Ads Integration

কিভাবে ফেসবুক (Meta) লিড অ্যাড কানেক্ট ও টেস্ট করবেন

ফেসবুক বা ইনস্টাগ্রাম বিজ্ঞাপনের Instant Form সাবমিট হওয়া মাত্রই রিয়েল-টাইমে সিআরএম-এ লিড চলে আসার পূর্ণাঙ্গ নির্দেশিকা।

⚡

রিয়েল-টাইম লিড ইনজেকশন

কাস্টমার ফেসবুকে ফরম পূরণ করার সাথে সাথে সিআরএম-এ চলে আসে এবং ৫ মিনিটের SLA টাইমার শুরু হয়।

🔑

স্থায়ী (Never Expire) টোকেন

টোকেন বারবার এক্সপায়ার হবে না। আজীবন চলবে এমন পার্মানেন্ট সিস্টেম ইউজার টোকেন সেটআপ।

🧪

১-ক্লিক টেস্টিং টুল

ফেসবুকের অফিসিয়াল টুল ও সিআরএম-এর ইন-অ্যাপ সিমুলেটর দিয়ে যেকোনো সময় টেস্ট করতে পারবেন।

১

Facebook Developer Account এবং Business App তৈরি করুন

ফেসবুকের সাথে সিআরএম কানেক্ট করার জন্য একটি Meta Business App প্রয়োজন।

  1. ব্রাউজারে যান: developers.facebook.com (আপনার ফেসবুক একাউন্টে লগইন করুন)।
  2. উপরের ডান কোনায় My Apps > Create App-এ ক্লিক করুন।
  3. App Type হিসেবে "Business" অথবা "Other > Business" নির্বাচন করুন।
  4. অ্যাপের নাম দিন (যেমন: Southeast Landmark CRM) এবং Create App বাটনে চাপুন।
  5. অ্যাপ তৈরি হলে বামের মেনু থেকে Add Product এ গিয়ে Webhooks এবং Lead Ads প্রোডাক্ট দুটি Set Up করুন।
  6. ড্যাশবোর্ড থেকে App ID কপি করে সিআরএম-এর Settings > Meta Webhook-এ সেভ করুন।
২

সিআরএম-এর সাথে Webhook ভেরিফাই ও কানেক্ট করুন

ফেসবুক এই নির্দিষ্ট ঠিকানায় আপনার বিজ্ঞাপন থেকে পাওয়া লিডগুলো পুশ করবে।

Meta Developer Portal-এ Webhooks মেনুতে যান > ড্রপডাউনে "Page" নির্বাচন করুন > "Subscribe to this object" এ ক্লিক করুন:

✓ Actual CRM URL

💡 লাইভ ফেসবুক অ্যাড এর জন্য জরুরি তথ্য:

• ফেসবুকের রুলস অনুযায়ী Webhook শুধুমাত্র HTTPS এ কাজ করে।

• লোকালহোস্টে টেস্ট করতে চাইলে Ngrok (যেমন: ngrok http 5000) বা ক্লাউড সার্ভার ডোমেইন ব্যবহার করুন।

ফেসবুকে এই টোকেনটি পেস্ট করবেন। দুটি মান পেস্ট করে ফেসবুকে "Verify and Save" চাপুন।

✅ ভেরিফাই সেভ হওয়ার পর, নিচে সাবস্ক্রিপশন তালিকায় `leadgen` ফিল্ডের পাশে Subscribe বাটনে ক্লিক করে দিন।

৩

Never-Expiring (স্থায়ী) Facebook Page Access Token তৈরি করার নিয়ম

সাধারণ টোকেন ১ ঘণ্টা বা ৬০ দিনে নষ্ট হয়ে যায়। এই পদ্ধতিতে আপনার টোকেন আজীবন সচল থাকবে!

★ পদ্ধতি ১: Meta Business System User (অফিসিয়াল ও সেরা পদ্ধতি)

Expires: Never
  1. ব্রাউজারে মেটা বিজনেস সেটিংসে যান: business.facebook.com/settings/system-users
  2. বামের মেনু থেকে Users > System Users এ যান।
  3. Add বাটনে ক্লিক করুন:
    • System Username: CRM Lead Automation
    • System User Role: Admin সিলেক্ট করে Create এ চাপুন।
  4. System User তৈরি হলে "Assign Assets" বাটনে ক্লিক করুন:
    • বাম থেকে Pages সিলেক্ট করে আপনার বিজ্ঞাপন চলা ফেসবুক পেজটি টিক দিন।
    • নিচে "Full Control" (Manage Page) টগল অন করে Save Changes চাপুন।
  5. এবার "Generate New Token" বাটনে ক্লিক করুন:
    • Select App: আপনার তৈরি করা CRM App টি বেছে নিন।
    • Token Expiration: ড্রপডাউন থেকে নির্বাচন করুন "Never" (স্থায়ী)।
    • Available Permissions তালিকায় এই পারমিশনগুলোতে টিক দিন:
      leads_retrieval pages_manage_ads pages_read_engagement pages_show_list
  6. নিচে "Generate Token" এ চাপুন। স্ক্রিনে একটি বিশাল টোকেন কোড আসবে (EAAB...)।
  7. টোকেনটি কপি করে আপনার সিআরএম-এর Settings > Meta Webhook > Page Access Token বক্সে পেস্ট করে দিন!

বিকল্প পদ্ধতি ২: Graph API Explorer এর মাধ্যমে পার্মানেন্ট পেজ টোকেন

বিকল্প
  1. যান: Graph API Explorer > Permissions এ leads_retrieval, pages_manage_ads, pages_read_engagement যোগ করে User Token তৈরি করুন।
  2. টোকেনটি নিয়ে যান: Token Debugger Tool > Debug চেপে নিচে "Extend Access Token" বাটনে ক্লিক করে ৬০ দিনের টোকেন বানান।
  3. পুনরায় Graph API Explorer এ এই টোকেন পেস্ট করে GET ফিল্ডে লিখুন: me/accounts?fields=name,access_token এবং Submit চাপুন।
  4. আপনার ফেসবুক পেজের নামের নিচে যে access_token পাবেন, সেটি সারাজীবন কখনোই এক্সপায়ার হবে না!
৪

App Secret ও পেজ সাবস্ক্রিপশন কনফার্ম করুন

ফেসবুকের পাঠানো তথ্যের নিরাপত্তা যাচাই ও পেজের সাথে লিংক নিশ্চিত করা।

  1. মেটা ডেভেলপার পোর্টালে App settings > Basic-এ গিয়ে App Secret কপি করে সিআরএম-এর Settings-এ সেভ করুন।
  2. পেজের লিড অ্যাপে রুট করতে Graph API Explorer-এ গিয়ে POST রিকোয়েস্ট পাঠান (অথবা টার্মিনালে রান করুন):
    curl -X POST "https://graph.facebook.com/v19.0/{PAGE_ID}/subscribed_apps?subscribed_fields=leadgen&access_token={PAGE_ACCESS_TOKEN}"
৫

কানেকশন টেস্ট ও লিড আসার প্রমাণ পরীক্ষা করুন

আপনার ফেসবুক লিড ইন্টিগ্রেশন ঠিকমতো কাজ করছে কিনা তা এই দুটি উপায়ে এখনই যাচাই করুন।

পদ্ধতি ১: সফটওয়্যারের ইন-অ্যাপ টেস্ট সিমুলেশন ইনস্ট্যান্ট

ফেসবুকে কোনো বিজ্ঞাপন রান না করেই সিআরএম নিজেই সম্পূর্ণ মেটা Webhook এর অনুরূপ ডাটা তৈরি করে লিড পরীক্ষা করতে পারে:

  1. সিআরএম-এর Settings > Meta Webhook ট্যাবে স্ক্রল করে নিচে নামুন।
  2. "Simulate Meta Lead (Webhook Test)" বক্সের ফরমটি পূরণ করুন।
  3. সবুজ "Simulate Lead Now" বাটনে ক্লিক করুন।
  4. সরাসরি Leads পেজে গিয়ে দেখুন লিডটি তৈরি হয়ে সেলস টিমের কাছে পৌঁছে গেছে এবং ৫ মিনিটের SLA কাউন্টডাউন শুরু হয়ে গেছে!
পদ্ধতি ২: ফেসবুকের অফিসিয়াল Lead Ads Testing Tool লাইভ মেটা টেস্ট

মেটার নিজস্ব সার্ভার থেকে আপনার সিআরএম সিস্টেমে লাইভ টেস্ট লিড পাঠান:

  1. ফেসবুকের এই লিংকে যান: Lead Ads Testing Tool
  2. আপনার Page এবং তৈরি করা Lead Form সিলেক্ট করুন।
  3. "Create Lead" বাটনে চাপ দিন।
  4. আপনার সিআরএম-এর Leads পেজ রিফ্রেশ করলেই ফেসবুকের পাঠানো লিড ও প্রশ্নোত্তরের ডাটা দেখতে পাবেন!

প্রয়োজনীয় টিপস ও সাধারণ সমস্যা সমাধান

  • Webhook Verify না হলে: নিশ্চিত করুন আপনার সিআরএম সার্ভারে বৈধ HTTPS চালু রয়েছে এবং Verify Token হুবহু মিলেছে।
  • টোকেন ভ্যালিড কিনা দেখার উপায়: যেকোনো সময় Access Token Debugger এ পেস্ট করে দেখুন Expire ডেট Never লেখা আছে কিনা।
  • প্রশ্নোত্তরের উত্তর কোথায় দেখাবে: যেকোনো লিডের পাশে View Profile → ক্লিক করলে ডেডিকেটেড পেজে ক্যাম্পেইনের সব প্রশ্নের উত্তর সুন্দরভাবে প্রদর্শিত হবে।

English Setup Summary

1. Register a Meta Business App at developers.facebook.com.

2. Set Callback URL to your active CRM domain + /api/webhooks/meta and enter the Verify Token from Settings.

3. Subscribe to the leadgen field under the Page object.

4. Generate a Never-Expiring Page Access Token using Meta Business Settings > System Users > Generate Token > Expiration: Never with leads_retrieval, pages_manage_ads, pages_read_engagement.

5. Test with either the In-App "Simulate Lead Now" button or Meta's Lead Ads Testing Tool.
