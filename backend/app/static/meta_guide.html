🚀 Meta Lead Ads Integration

Facebook (Meta) Lead Ads কানেক্ট গাইড — একদম শুরু থেকে শেষ

কোনো টেকনিক্যাল জ্ঞান ছাড়াই — শুধু ক্লিক, কপি আর পেস্ট। ধাপগুলো একে একে অনুসরণ করলেই Facebook Page-এর লিড সরাসরি CRM-এ চলে আসবে। সময় লাগবে প্রায় ২০–৩০ মিনিট। কাজটা কম্পিউটার/ল্যাপটপে করুন।

⭐ এই CRM-এর জন্য সুখবর — বেশিরভাগ কাজ ইতিমধ্যে করা আছে

  • Meta App "Southeast Landmark CRM" (App ID: 988028163659869) ইতিমধ্যে তৈরি ও Published। তাই সাধারণত ধাপ ১–৮ করতে হবে না — শুধু ধাপ ৯ (Connect) আর ধাপ ১০ (টেস্ট) করলেই হবে। ধাপ ১–৮ রাখা হলো ভবিষ্যতে একদম নতুন করে সেটআপ করতে হলে যেন পারেন।
  • Privacy Policy URL লাইভ: https://southeastlandmark.pythonicshariful.tech/privacy-policy.html — Data Deletion: একই URL + #data-deletion
  • ⚠️ southeastlandmark.com কখনো ব্যবহার করবেন না — ওই ডোমেইন এখন অন্যের দখলে (জুয়ার সাইট দেখায়)। Meta-র কোনো ঘরে ওই ডোমেইনের লিংক দিলে অ্যাপ ব্লক হতে পারে।

শুরু করার আগে — যা যা লাগবে

  • একটা Facebook অ্যাকাউন্ট, যেটা কোম্পানির Facebook Page-এর Admin। (Admin না হলে কানেক্ট হবে না।)
  • কোম্পানির Facebook Page — যে পেজে বিজ্ঞাপন আর লিড ফর্ম চলবে।
  • CRM-এর Admin লগইন — শুধু Admin-ই Meta কানেক্ট করতে পারবে।
  • কম্পিউটার ও ইন্টারনেট।

🔒 App Secret আর Verify Token হলো পাসওয়ার্ডের মতো — কাউকে পাঠাবেন না, স্ক্রিনশটে শেয়ার করবেন না।

এক নজরে পুরো কাজটা: Meta App তৈরি → দুটো Product যোগ → CRM থেকে ৩টা লিংক কপি → Meta App-এ বসানো → App Publish → CRM-এ App ID/Secret সেভ → Connect with Facebook → Page বাছাই → টেস্ট লিড → সম্পন্ন ✅

১

Meta App তৈরি করা

  1. ব্রাউজারে যান: developers.facebook.com — নিজের Facebook অ্যাকাউন্ট দিয়ে লগইন করুন। (প্রথমবার হলে "Get Started" চেপে Developer হিসেবে রেজিস্টার করুন।)
  2. ওপরে My Apps → Create App চাপুন।
  3. "What do you want your app to do?" আসলে Other বেছে নিন → Next।
  4. App type-এ Business বেছে নিন → Next।
  5. অ্যাপের নাম দিন (যেমন: Southeast Landmark CRM), নিজের ইমেইল দিন → Create App। Facebook পাসওয়ার্ড চাইলে দিন।

⚠️ অনেকের ভুল হয় এখানে: শুধু "Facebook Login" দিয়ে অ্যাপ বানালে পরে "Invalid Scopes" এরর আসে। তাই অবশ্যই Other → Business নিন।

২

অ্যাপে দুটো Product যোগ করা

  1. অ্যাপের Dashboard-এ "Add products to your app" অংশে Facebook Login খুঁজে Set up চাপুন।
  2. আবার Dashboard-এ ফিরে Webhooks খুঁজে Set up চাপুন।

দুটোই লাগবে: Facebook Login ছাড়া CRM-এর Connect বাটন কাজ করবে না, Webhooks ছাড়া লিড CRM-এ আসবে না।

৩

CRM থেকে ৩টা জিনিস কপি করে রাখা

  1. CRM-এ Admin দিয়ে লগইন করুন → Settings → Meta ট্যাবে যান।
  2. Callback Webhook URL আর Verify Token — "Meta Webhook Configuration" কার্ডে পাবেন।
  3. Redirect URI — ওপরের "Facebook App credentials" অংশ খুললেই পাবেন।
  4. প্রতিটার পাশে Copy বাটন আছে — হাতে লিখতে হবে না। এই ট্যাবটা ব্রাউজারে খোলা রাখুন।
৪

Facebook Login-এ Redirect URI বসানো

  1. Meta App-এর বাম মেনুতে Facebook Login → Settings যান।
  2. Valid OAuth Redirect URIs বাক্সে CRM থেকে কপি করা Redirect URI পেস্ট করুন।
  3. নিচে Save Changes চাপুন।
৫

Webhooks সেটআপ (লিড আসার রাস্তা)

  1. Meta App-এর বাম মেনুতে Webhooks যান।
  2. ওপরের ড্রপডাউন থেকে Page বেছে নিন।
  3. Callback URL-এ CRM-এর Callback Webhook URL পেস্ট করুন।
  4. Verify Token-এ CRM-এর Verify Token হুবহু পেস্ট করুন → Verify and Save চাপুন। (ঠিকঠাক হলে এরর আসবে না।)
  5. নিচের তালিকায় leadgen খুঁজে Subscribe চাপুন।

ℹ️ পেজের আসল সংযোগটা ধাপ ৯-এ Connect করার সময় CRM নিজে থেকেও চালু করে দেয় — তবু এখানে Subscribe করে রাখা নিরাপদ।

৬

অ্যাপের Basic তথ্য (Publish-এর জন্য লাগবে)

  1. বাম মেনুতে Settings → Basic যান।
  2. Privacy Policy URL-এ বসান: https://southeastlandmark.pythonicshariful.tech/privacy-policy.html
  3. User Data Deletion-এ (URL অপশন থাকলে) বসান: https://southeastlandmark.pythonicshariful.tech/privacy-policy.html#data-deletion
  4. Category বেছে দিন (যেমন Business) আর App Icon-এ কোম্পানির লোগো আপলোড করুন।
  5. Save Changes চাপুন। এই পেজেই ওপরে App ID পাবেন; App Secret দেখতে "Show" চেপে Facebook পাসওয়ার্ড দিতে হয় — দুটোই ধাপ ৭-এ লাগবে।
৭

App ID ও App Secret CRM-এ বসানো

  1. CRM-এ ফিরে যান → Settings → Meta → "Facebook App credentials" অংশ খুলুন।
  2. App ID আর App Secret পেস্ট করুন → Save চাপুন।
  3. "App credentials saved — click Connect with Facebook" মেসেজ এলেই সেভ হয়েছে।
৮

অ্যাপ Publish করা (Live করা)

  1. Meta App-এর Dashboard-এ যান। অ্যাপ Unpublished দেখালে ওপরে Publish বাটন চাপুন।
  2. Meta যা যা অসম্পূর্ণ দেখাবে (Privacy Policy, Icon, Category) পূরণ করে আবার Publish চাপুন।

⚠️ Publish না করলে শুধু অ্যাপের Admin/Tester-দের টেস্ট লিড আসবে — আসল গ্রাহকের লিড আসবে না। এই ধাপ বাদ দেওয়া যাবে না।

৯

CRM থেকে Connect করা ⭐ (সাধারণত এখান থেকেই শুরু)

  1. CRM-এ Admin লগইন → Settings → Meta ট্যাব।
  2. নীল Connect with Facebook বাটন চাপুন।
  3. Facebook উইন্ডো খুলবে — যে অ্যাকাউন্ট Page-এর Admin, সেই অ্যাকাউন্ট দিয়ে লগইন করুন।
  4. Page বাছাইয়ের স্ক্রিনে কোম্পানির আসল Page-টিতে টিক দিন → Continue / Next।
  5. অনুমতি (Permission) চাইলে সবগুলো Allow / OK করুন — একটা বাদ দিলেও লিড আসবে না।
  6. সফল হলে CRM-এ ফিরে আসবেন: Connect কার্ডে সবুজ LIVE ব্যাজ আর "Connected to ‹Page-এর নাম›" দেখাবে, নিচে পেজের Lead Form-গুলোর তালিকা চলে আসবে।
১০

টেস্ট লিড পাঠিয়ে পরীক্ষা ⭐ (সবচেয়ে গুরুত্বপূর্ণ)

পদ্ধতি A — Meta-র অফিসিয়াল টেস্ট টুল (আসল পরীক্ষা):

  1. নতুন ট্যাবে যান: developers.facebook.com/tools/lead-ads-testing
  2. Page ড্রপডাউনে আপনার Page বেছে নিন → নিচে Form বেছে নিন।
  3. Create lead চাপুন (প্রিভিউ এলে তথ্য রেখে Submit করুন)।
  4. CRM-এর Leads পেজে যান → ১ মিনিটের মধ্যে নতুন লিড সবার ওপরে NEW হিসেবে আসবে ✅ (নাম "Meta Test Lead" জাতীয় দেখাতে পারে — স্বাভাবিক)।
  5. টেস্ট শেষে ওই টুলেই আগের টেস্ট লিডটা Delete lead করে মুছে দিন — নাহলে পরেরবার একই ফর্মে আবার টেস্ট করা যাবে না।

পদ্ধতি B — CRM-এর নিজের টেস্ট (সহজ): Settings → Meta-তে "Simulate Meta Lead (Test Without Real Ads)" প্যানেলে Simulate Lead Now চাপুন → Leads পেজে নমুনা লিড আসবে। এটা শুধু CRM-এর ভেতরের পরীক্ষা; Facebook থেকে সত্যিই লিড আসবে কিনা তার প্রমাণ শুধু পদ্ধতি A।

১১

আসল লিড এলে যা হবে + Page বদলানো

  • কেউ Facebook বিজ্ঞাপনের ফর্ম পূরণ করলেই লিড কয়েক সেকেন্ডের মধ্যে CRM-এর Leads পেজে NEW হিসেবে চলে আসবে — কিছুই করতে হবে না।
  • সেট করা নিয়ম অনুযায়ী লিড নিজে থেকেই টিমের একজনের কাছে assign হয়ে যাবে।
  • লিড খুললেই (Lead Details) ফর্মের সব উত্তর দেখা যাবে।
  • Page বদলাতে হলে: Settings → Meta → Disconnect → ধাপ ৯ আবার করুন (নতুন Page বেছে) → ধাপ ১০ দিয়ে আবার টেস্ট করুন।

সমস্যা হলে — সহজ সমাধান

যা দেখছেনকারণ ও সমাধান
"Invalid Scopes" এরর অ্যাপ ভুলভাবে তৈরি হয়েছে (শুধু Facebook Login দিয়ে)। ধাপ ১ অনুযায়ী Other → Business দিয়ে অ্যাপ হতে হবে — আমাদের জানান।
Connect চাপলে "Add your Facebook App ID and App Secret first" আগে ধাপ ৭ করুন — credentials সেভ করা হয়নি।
Connect সফল, কিন্তু টেস্ট লিড আসছে না একে একে দেখুন: (ক) অ্যাপ Publish হয়েছে তো? (ধাপ ৮) (খ) ঠিক Page-টা বেছেছিলেন তো? (গ) Webhooks-এ leadgen Subscribe আছে তো? (ধাপ ৫) — তারপর Disconnect করে আবার Connect করুন (ধাপ ৯) আর আবার টেস্ট করুন (ধাপ ১০)।
লিড আসছে কিন্তু নাম "Unknown" Facebook ফর্মের প্রশ্নের নাম স্ট্যান্ডার্ডভাবে দেওয়া হয়নি। সব উত্তর Lead Details-এর "Custom Lead Form Answers"-এ পাবেন। আমাদের জানালে মূল ঘরেও সাজিয়ে দেওয়া যাবে।
অন্যের অ্যাকাউন্ট দিয়ে Connect হচ্ছে না শুধু Page-এর Admin অ্যাকাউন্ট দিয়েই হবে, আর CRM-এ Admin লগইন লাগবে।
কানেকশন হঠাৎ ভেঙে গেছে মনে হচ্ছে Page-এর Admin বদলালে বা Facebook পাসওয়ার্ড বদলালে এমন হতে পারে। Disconnect করে আবার Connect করুন।

শেষ কথা — মনে রাখুন ৩টা জিনিস

  1. 🔒 App Secret / Verify Token কাউকে দেবেন না।
  2. 👀 মাঝে মাঝে Settings → Meta কার্ডে সবুজ LIVE ব্যাজটা দেখে নিন — থাকলেই সংযোগ ঠিক আছে।
  3. 🧪 Page বা ফর্ম বদলালেই ধাপ ১০-এর টেস্ট আবার করুন — টেস্ট লিড এলেই নিশ্চিত।
